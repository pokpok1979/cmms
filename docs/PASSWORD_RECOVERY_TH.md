# ตั้งค่าลืมรหัสผ่านผ่านอีเมล

หน้าเข้าสู่ระบบมีปุ่ม **ลืมรหัสผ่าน?** ผู้ใช้ระบุอีเมลที่บันทึกไว้ในบัญชี ระบบส่งลิงก์ตั้งรหัสผ่านใหม่ให้บัญชีที่เปิดใช้งานอยู่เท่านั้น ผู้ใช้ที่ไม่มีอีเมลหรือถูกระงับต้องติดต่อ Admin

Admin เปิดเมนู **ตั้งค่า SMTP** ในกลุ่มระบบและผู้ใช้งาน เลือกบริษัทในตารางแล้วกรอก SMTP Server, พอร์ต, TLS/StartTLS, ชื่อผู้ใช้และรหัสผ่าน, อีเมลและชื่อผู้ส่ง และ URL ของ CMMS สำหรับลิงก์ตั้งรหัสผ่านใหม่ จากนั้นเปิดใช้งานและบันทึก ข้อมูลจัดเก็บในตาราง `smtpSettings` โดยไม่ต้องตั้งค่า SMTP ในไฟล์ `.env` และไม่ต้องรีสตาร์ตเมื่อแก้ไข

ผู้ดูแลต้องมีสิทธิ์ครบทุกสาขาในบริษัทจึงจะดูหรือแก้ไข SMTP ของบริษัทนั้นได้ ฟังก์ชันลืมรหัสผ่านเลือกบริษัทที่ผูก LDAP ของผู้ใช้เมื่อบริษัทยังอยู่ในสิทธิ์ หากไม่มีจะใช้บริษัทแรกในสิทธิ์ผู้ใช้

รหัสผ่านเข้ารหัสด้วย AES-256-GCM โดยใช้ `SMTP_ENCRYPTION_KEY` บนเซิร์ฟเวอร์ หรือ `LDAP_ENCRYPTION_KEY` เดิมเมื่อไม่ได้ตั้งค่าคีย์แยก คีย์ต้องเป็น hexadecimal 64 ตัวอักษรและเก็บไว้นอกฐานข้อมูล หากเซิร์ฟเวอร์มีคีย์ LDAP อยู่แล้วไม่ต้องเพิ่มคีย์ใหม่ ห้ามเปลี่ยนคีย์โดยไม่มีแผนย้ายข้อมูลที่เข้ารหัสแล้ว

หน้าเว็บจะไม่ส่งรหัสผ่านหรือค่าที่เข้ารหัสกลับมายังเบราว์เซอร์ แสดงเพียงว่ามีรหัสผ่านอยู่แล้ว เว้นช่องรหัสผ่านว่างเพื่อใช้ค่าเดิม หากใช้ SMTP relay ที่อนุญาตเซิร์ฟเวอร์โดย IP ให้ปิดตัวเลือกยืนยันตัวตน ซึ่งจะลบรหัสผ่าน SMTP ที่บันทึกไว้

พอร์ต 587 ใช้ StartTLS และพอร์ต 465 ใช้ TLS ตั้งแต่เริ่มเชื่อมต่อ ระบบตรวจสอบใบรับรองตามปกติ ผู้ให้บริการต้องรองรับ SMTP และวิธียืนยันตัวตนที่กำหนดไว้ อ้างอิง [Nodemailer SMTP](https://nodemailer.com/smtp)

ลิงก์อ้างอิง URL ระบบที่กรอกในตาราง SMTP ไม่ใช้ Host จากคำขอ และมีอายุ 15 นาที ใช้ได้ครั้งเดียว เก็บเฉพาะแฮชของ token ใน MongoDB ตาราง passwordResets มี TTL index ซึ่งระบบสร้างให้เมื่อมีคำขอแรก การตรวจวันหมดอายุทำใน API ด้วย ไม่รอ TTL ลบเอกสาร

เมื่อตั้งรหัสผ่านสำเร็จ ระบบยกเลิกทุก session และทุกลิงก์เดิมของบัญชีนั้น หาก Admin เปลี่ยนรหัสผ่านหรืออีเมลระหว่างรอ ลิงก์ก่อนหน้าจะใช้ไม่ได้ รหัสผ่านใหม่ต้องมีอย่างน้อย 12 ตัวอักษร

API ตอบข้อความเดียวกันสำหรับอีเมลที่มีบัญชี ไม่มีบัญชี หรือบัญชีถูกระงับ พร้อมจำกัดจำนวนคำขอ การส่งอีเมลผิดพลาดบันทึกเป็นข้อความทั่วไปพร้อมรหัสอ้างอิง โดยไม่บันทึกลิงก์ รหัสผ่าน หรือ SMTP credential

หลังบันทึกและเปิดใช้งาน ให้กด **ทดสอบการเชื่อมต่อ** เพื่อตรวจการเชื่อมต่อและยืนยันตัวตน ปุ่มนี้ยังไม่ส่งอีเมลและไม่ยืนยันว่าผู้ให้บริการอนุญาต From address นั้น ขั้นสุดท้ายให้กดลืมรหัสผ่านด้วยบัญชีทดสอบที่เปิดใช้งาน ตรวจรับอีเมล ตั้งรหัสผ่านใหม่ และตรวจว่าลิงก์เดิมใช้ซ้ำไม่ได้

หาก SMTP ยังไม่พร้อม บัญชีสาธารณะยังได้รับข้อความทั่วไปแบบเดียวกันเพื่อไม่เปิดเผยว่าบัญชีมีอยู่จริง ผู้ดูแลตรวจรายละเอียดความพร้อมได้จากหน้าตั้งค่าและผลทดสอบ ขณะพัฒนายังไม่ได้ส่งอีเมลจริงหากไม่มีค่าการเชื่อมต่อ SMTP
