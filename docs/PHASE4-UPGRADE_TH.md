# คลังอะไหล่ Phase 4

ติดตั้งจาก AGE_CMMS_Phase4_Inventory.zip พร้อมเชื่อมเมนูคลังอะไหล่ สิทธิ์ inventory การแจ้งเตือน และประวัติการเปลี่ยนแปลงกับระบบปัจจุบัน

เปิดจากเมนูคลังอะไหล่ หรือ /inventory หลังเข้าสู่ระบบ รองรับรับเข้า เบิกเข้าใบงาน คืนอ้างอิงรายการเบิก ยอดคงเหลือ ประวัติ และรายงาน Excel ต้นทุนอะไหล่ดูที่แท็บต้นทุนตามใบงาน

เรียก npm run setup:inventory เพื่อสร้างดัชนี โดยไม่เพิ่มยอดหรือแก้ผู้ใช้

ก่อนใช้จริงให้ทดสอบตาม PHASE4_UAT_TH.md โดยเฉพาะรายการพร้อมกันและ transaction rollback ด้วยฐานข้อมูลทดสอบ เอกสาร PHASE4_INSTALL_TH.md และ PHASE4_TESTING.md เป็นเอกสารต้นฉบับจาก ZIP ไม่ใช่ผลตรวจสอบระบบปัจจุบัน
