# UAT Phase 4
ใช้ฐานข้อมูลทดสอบก่อนเปิด Production

| กรณี | ผลที่ต้องได้ |
|---|---|
| ติดตั้งและรัน setup แล้วเปิด /inventory | เพิ่มส่วนใหม่ได้ Login/Users/PM/งานซ่อมเดิมยังทำงาน |
| เพิ่มรหัสอะไหล่ซ้ำในบริษัท/ไซต์เดียวกัน | ปฏิเสธ รหัส normalize เป็นตัวพิมพ์ใหญ่ |
| รหัสเดียวกันต่างไซต์ | สร้างได้เมื่อมีสิทธิ์ทั้งสองพื้นที่ |
| ผู้ใช้ไม่มี grant หรือ requester เรียก API โดยตรง | ไม่เห็นและแก้ไข stock ไม่ได้ |
| รับ 10 หน่วย ราคา 100 บาท แล้วรับ 10 หน่วย ราคา 200 บาท | คงเหลือ 20 หน่วย มูลค่า 3,000 บาท |
| เบิก 5 หน่วยจากยอดข้างบนเข้า WO | คงเหลือ 15 หน่วย มูลค่า 2,250 บาท ต้นทุนอะไหล่ WO เพิ่ม 750 บาท |
| คืน 2 หน่วยจากรายการเบิกข้างบน | คงเหลือ 17 หน่วย มูลค่า 2,550 บาท ต้นทุนอะไหล่ WO เหลือ 450 บาท |
| คืนอีก 3 หน่วย | คงเหลือ 20 หน่วย มูลค่า 3,000 บาท ต้นทุนอะไหล่ WO กลับเป็นศูนย์ |
| คืนเกินจำนวนเบิก หรือนำ receipt มาเป็น issueId | ปฏิเสธ ไม่มี stock/cost เปลี่ยน |
| ช่างที่ไม่ได้รับมอบหมาย WO หรือ WO ต่างไซต์ | เบิกไม่ได้ รวมเรียก API โดยตรง |
| เบิกเข้า WO completed/cancelled/review/unassigned | ปฏิเสธ |
| Admin คืนจาก WO ปิดแล้ว | คืนได้ อ้างรายการเดิม ระบุเหตุผล และมี Audit |
| ช่างคืนจาก WO ปิดแล้วหรือรายการคนอื่นเบิก | ปฏิเสธ |
| ผู้ใช้สองคนเบิกยอดสุดท้ายพร้อมกัน | ยอดไม่ติดลบ ผู้สำเร็จเท่านั้นมี ledger/ต้นทุน WO |
| คืนจาก issue เดียวพร้อมกันสองหน้าต่าง | ยอดคืนรวมไม่เกินยอดเบิก และต้นทุนไม่ติดลบ |
| ส่ง POST key เดิมและ payload เดิมซ้ำ | มีรายการเดียว ส่งเลขรายการเดิมกลับมา |
| ส่ง key เดิมแต่เปลี่ยนจำนวน | ปฏิเสธ ไม่ลงรายการเพิ่ม |
| จำลอง transaction ล้มเหลว | stock/ledger/ต้นทุน WO/notification ย้อนกลับพร้อมกัน ไม่มีบางส่วนค้าง |
| stock ลงถึงจุดสั่งซื้อ | แสดง dashboard และ notification ให้ผู้จัดการที่มี grant ตรงพื้นที่ |
| ยังต่ำแล้วเบิกเพิ่ม | ไม่แจ้งซ้ำ จนกว่าจะกลับสูงกว่าจุดสั่งซื้อแล้วลงต่ำอีกครั้ง |
| รับ fractional qty, คืนหลายครั้ง และเบิกจนหมด | ไม่เหลือมูลค่าเศษเมื่อ qty เป็นศูนย์ มูลค่าที่คืนครบเท่าต้นทาง |
| เปลี่ยนหน่วยเมื่อมี movement หรือเปลี่ยนไซต์/รหัสเดิม | ปฏิเสธ |
| ระงับอะไหล่ | รับ/เบิกใหม่ไม่ได้ แต่คืนอ้างรายการเดิมได้ |
| รายงานใบงาน | ค่าใช้จ่ายเดิมไม่ถูกแก้ ยอดรวม = ค่าใช้จ่ายเดิม + อะไหล่สุทธิ |
| Excel ทั้งสามรายงาน | ข้อมูลตรงตัวกรองทุกหน้า ภาษาไทยและตัวเลขถูกต้อง ไม่มีสูตรจากข้อความผู้ใช้ |
| Desktop/Mobile | ฟอร์มใช้งานได้ ตารางเลื่อนในกรอบได้ ปุ่มยืนยันไม่ซ้ำขณะรอ |

ข้อควรทดสอบเพิ่มเติมกับ source ปัจจุบันขององค์กร:
- หน้าเมนูและการแสดง notification เดิม
- ขั้นตอนเปลี่ยนสถานะ WO พร้อมกับการเบิกในอีกหน้าต่าง ต้องไม่ทำให้ revision หรือต้นทุนผิด
- สิทธิ์ Atlas / backup restore / การใช้งานผ่าน HTTPS / Next.js security upgrade
