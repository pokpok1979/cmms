# AGE CMMS Phase 3 — PM Advanced
ส่งมอบ 22 ตุลาคม 2569

## สิ่งที่เพิ่มในชุดนี้
1. รูปก่อน/หลังงาน PM: JPG/PNG สูงสุด 8 MB ต่อรูป, 20 รูปต่องาน จัดเก็บ R2 private bucket เดิม เปิดผ่าน signed URL อายุ 60 วินาทีหลังตรวจสิทธิ์
2. ปฏิทินรายเดือน: แสดงงานจริงและแผนล่วงหน้าแบบเส้นประ แผนล่วงหน้ายังไม่ใช่ใบงานหรือผลตรวจ
3. แก้ไขแผนพร้อมเวอร์ชัน: เก็บชื่อ รอบ ช่าง Checklist ระยะเตือน และผู้แก้ไข งานที่สร้างแล้วไม่เปลี่ยนตามแผนเวอร์ชันใหม่
4. สร้างใบแจ้งซ่อมจาก Checklist ไม่ผ่าน: ช่างรับผิดชอบหรือผู้จัดการกดสร้าง โดยกรอกรายละเอียด/ผู้ติดต่อ/แผนก แล้วเข้า repairRequests สถานะรออนุมัติตาม Phase 1 ป้องกันสร้างซ้ำต่อหนึ่งงาน PM
5. แจ้งเตือนในระบบ: ก่อนกำหนด 0–30 วัน, ถึงกำหนด, เกินกำหนด ส่งให้ช่างรับผิดชอบ แต่ละประเภทส่งครั้งเดียวต่องาน ไม่ส่งรายวันซ้ำ
6. รายงาน: ค้นหา/ช่วงวัน/สถานะ, แบ่งหน้า, ตัวเลขภาพรวมจากฐานข้อมูล และดาวน์โหลด Excel .xlsx จริง ไม่ต้องติดตั้งแพ็กเกจ Excel เพิ่ม

## ต้องมีอะไรอยู่ก่อน
- ติดตั้งชุด Phase 1 และ Phase 2 PM จากแชตนี้แล้ว
- custom auth.ts ที่ใช้ cmms_session (ไม่ใช่ better-auth)
- Node 24 + dependencies ของ Phase 1 รวม tsx และ @next/env
- MongoDB Atlas ที่รองรับ transactions, สิทธิ์อ่านเขียนและสร้าง indexes, IP Access List ถูกต้อง
- R2: R2_ENDPOINT, R2_BUCKET, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY สำหรับรูปภาพ
- APP_URL ตรงกับ origin ของเว็บจริง

## ติดตั้ง Windows / VS Code
หยุดเว็บและหยุด Task Scheduler ของ PM ก่อน สำรองทั้งโค้ดและฐานข้อมูลก่อนติดตั้ง
แตก ZIP ไว้นอกโฟลเดอร์โปรเจกต์ เช่น C:\CMMS_Phase3
เปิด Terminal ในโฟลเดอร์ cmms แล้วรัน (เปลี่ยนพาธให้ตรง):

```powershell
node C:\CMMS_Phase3\install.cjs .
node --import tsx scripts/setup-pm3.ts
npm run typecheck
npm test
npm run build
npm run dev
```

จากนั้น Login ด้วยบัญชีเดิมแล้วเปิด:
http://localhost:3000/pm/advanced

ปรับ hostname/port ให้ตรงเครื่องที่ใช้จริง เพิ่มลิงก์ /pm/advanced ใน sidebar เดิมได้ด้วยตนเอง
หน้า /pm เดิมยังอยู่ แต่ควรใช้ /pm/advanced เป็นหน้าหลักสำหรับงาน PM รุ่นนี้

Installer เพิ่มไฟล์ใหม่และเปลี่ยนเพียง src/lib/pm-engine.ts จากชุด Phase 2 ที่รู้จัก เพื่อให้ปุ่มและ worker เดิมเรียก engine ใหม่
ไม่แก้ auth.ts, db.ts, หน้า Login, Users, Audit, globals.css, package.json หรือ .env.local
มีการตรวจ hash ไฟล์เดิม: หากคุณแก้ pm-engine.ts เอง Installer จะหยุดก่อนคัดลอก ให้เทียบความต่างก่อนรวมโค้ด
สำรองไฟล์ที่เปลี่ยนพร้อม manifest ในโฟลเดอร์ phase3-backup-... และติดตั้งซ้ำได้ถ้าไฟล์ตรงกัน
setup-pm3 เพิ่ม index ไม่ล้าง collection ไม่ seed/reset ผู้ใช้ ไม่เรียก collMod

## การตั้งเวลา
ใช้ Task Scheduler เดิมจาก Phase 2 ทุก 5 นาทีได้ หลังติดตั้ง bridge pm-engine.ts แล้ว worker เดิมจะทำงาน Phase 3
ทดสอบจากโฟลเดอร์ cmms:

```powershell
node --import tsx scripts/pm-worker.ts
```

Task Scheduler:
- Program: พาธ node.exe
- Arguments: --import tsx scripts/pm-worker.ts
- Start in: พาธเต็มของ cmms ที่มี .env.local
- ทำซ้ำทุก 5 นาที / เลือกไม่เริ่มซ้อนเมื่อ task เดิมยังรัน
- เครื่องที่รันต้องเปิดอยู่และเข้าถึง Atlas ได้
- เปิด Task กลับหลังติดตั้งเสร็จ

worker ใช้ transaction lock ร่วมกับการแก้แผน สร้างสูงสุด 20 แผน × 20 รอบต่อการรัน และแจ้งเตือนถึงกำหนด/เกินกำหนดไม่เกินประเภทละ 200 งาน การรันครั้งถัดไปทำต่อ
งานล่วงหน้าจะถูกสร้างเมื่อเข้า leadDays (ค่าเริ่มต้น 3 วันสำหรับแผนเดิม)
การพักแผนหยุดสร้างงานใหม่ งานที่สร้างแล้วรวมถึงแจ้งเตือนงานค้างยังคงอยู่

## วิธีใช้งาน
### Admin / Supervisor
- เพิ่มหรือแก้แผนจากแท็บจัดการแผน PM; เลือกช่างที่มีสิทธิ์พื้นที่เดียวกับทรัพย์สิน
- แก้ชื่อ/Checklist/ช่าง/leadDays มีผลเฉพาะงานที่ยังไม่สร้าง
- หากเปลี่ยนรอบหรือวันเริ่มต้น ให้ตั้งวันเริ่มต้นตั้งแต่วันนี้ ระบบใช้รอบใหม่ต่อไป
- เปลี่ยนทรัพย์สินของแผนเดิมไม่ได้ ให้สร้างแผนใหม่
- หากรอบใหม่ตรงวันที่มีงานเดิม จะใช้งานเดิมวันนั้น ไม่สร้างงานซ้ำ
- ดูประวัติเวอร์ชันได้ แผนจาก Phase 2 จะเริ่มมี snapshot เมื่อแก้ไขผ่าน Phase 3
- สร้างใบแจ้งซ่อมจากงานที่มีผลไม่ผ่านได้ ไม่สร้างให้อัตโนมัติโดยไม่มีการยืนยัน

### Technician
- เห็นเฉพาะงานที่ได้รับมอบหมายในพื้นที่ที่มีสิทธิ์
- เปิดงาน แนบรูปก่อน/หลัง ตรวจ Checklist ให้ครบ ระบุหมายเหตุ แล้วกดยืนยันปิดงาน
- แนบรูปทั้งก่อนและหลังให้เสร็จก่อนปิดงาน งานที่ปิดแล้วอ่านได้แต่แนบเพิ่มไม่ได้
- เมื่อมีข้อไม่ผ่าน กดสร้างใบแจ้งซ่อม กรอกรายละเอียดและผู้ติดต่อ แล้วติดตามจากระบบหลัก

### Calendar / Report
- ปฏิทินเลือกเดือน รายการเส้นประคือแผนที่ยังไม่สร้างงาน จึงคลิกบันทึกผลไม่ได้
- ปฏิทินใช้ตัวกรองชื่อและสถานะจากส่วนค้นหา แต่ช่วงวันที่รายงานไม่เปลี่ยนเดือนปฏิทิน
- รายงานกรองจากวันครบกำหนด (due) ไม่ใช่วันที่บันทึกผล
- จำนวนเสร็จภายในกำหนด เทียบวันเสร็จในเขตเวลา Asia/Bangkok กับ due
- Excel ใช้เงื่อนไขค้นหาเดียวกับรายงาน ส่งออกทุกหน้าสูงสุด 10,000 งาน ไม่รวมรูปไฟล์จริงและแผนล่วงหน้า

## ขีดจำกัด / ขอบเขต
- รายการแผนแสดงสูงสุด 500 แผน; lookup ทรัพย์สิน/ช่างสูงสุดอย่างละ 1,000; ประวัติเวอร์ชันแสดงล่าสุด 100
- ปฏิทินรองรับสูงสุด 500 แผนที่ใช้งานและ 2,000 รายการรวมต่อช่วง เลือกเดือน/กรองชื่อให้แคบลงถ้าเกิน
- รายงานช่วงสูงสุด 366 วัน แบ่งหน้าละ 30 งาน; Export เกิน 10,000 ต้องลดช่วง
- รูปไม่ผ่านการสแกนไวรัส ตรวจชนิดจาก magic bytes และ MIME ไม่รองรับ SVG/HEIC
- ถ้าไม่มี R2 ยังใช้แผน/Checklist/ปฏิทิน/รายงานได้ แต่แนบและเปิดรูปไม่ได้
- ยังไม่รวม Email/Teams/LINE, อะไหล่/สต็อก, รอบมิเตอร์, อนุมัติผล PM และ offline
- ไม่มีการย้ายข้อมูลจากระบบอื่น ชุดนี้ต่อจาก source Phase 1/2 ในบทสนทนา

## ย้อนกลับ
หยุดเว็บ/worker คืนไฟล์ pm-engine.ts จากโฟลเดอร์ backup และนำไฟล์ใหม่ตาม manifest ออก
ถ้ามีการแก้รอบแผนหรือสร้างข้อมูล Phase 3 แล้ว ควรคืนฐานข้อมูลจาก backup ที่ตรงกับ code แทนการย้อนเฉพาะไฟล์ เพราะ Phase 2 ไม่รองรับเวอร์ชันแผนแบบใหม่
