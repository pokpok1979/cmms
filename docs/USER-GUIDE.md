# คู่มือแยกบทบาท
## ผู้แจ้ง
เข้าสู่ระบบ → แจ้งซ่อม → เลือกสาขา/สถานที่ → เครื่องจักรเลือกหรือเว้นว่าง → ระบุอาการ/ความเร่งด่วน → บันทึก. เลือกภาพจากกล้องก่อนบันทึกได้ ระบบสร้างเลข RR แล้วอัปโหลดให้อัตโนมัติ; แนบเพิ่มเติมในรายละเอียดได้. งานจะไม่หายหาก upload ล้มเหลว ให้แนบใหม่. ดูคำขอของตนเอง แสดงความคิดเห็น. หลังหัวหน้าตรวจรับ WO ครบ เลือกคะแนนและยืนยันปิด. ถ้าใบงานยังไม่เสร็จ backend จะปฏิเสธ.
## หัวหน้างาน
เปิดคำขอ pending → อนุมัติและสร้าง WO → เปิดใบงาน → เลือกช่าง/กำหนดเสร็จ → มอบหมาย. ตรวจบันทึกและผลทดสอบใน review → เสร็จสิ้น หรือส่งกลับพร้อมเหตุผล. ยกเลิก/ไม่อนุมัติต้องระบุเหตุผล. ยกเลิก WO จะยกเลิกคำขอต้นทางด้วยใน MVP ที่มีหนึ่ง WO ต่อคำขอ และบันทึกเหตุผล; หากต้องซ่อมต่อให้สร้างคำขอใหม่.
## ช่าง
งานของฉัน → รับงาน → กำลังดำเนินการ → บันทึกสาเหตุ/วิธีแก้/ผลทดสอบ/เวลา/ค่าใช้จ่าย → ส่งตรวจรับ. รออะไหล่/รอผู้รับเหมา แล้วกลับกำลังดำเนินการได้. ช่างกด completed เองไม่ได้. ระบบไม่ใช้ labor hours เป็น Downtime.
## ผู้บริหาร
ดู Dashboard และข้อมูลใน site grants แบบอ่านอย่างเดียว; จำนวนงานอิงข้อมูลจริง ไม่แสดง KPI ที่ยังไม่พัฒนา.
## Admin
ดู users/เพิ่มผู้ใช้ เลือกบทบาทและสาขาภายในสิทธิ์ของตนเอง. เพิ่มสถานที่และ asset; ตรวจ audit log. เพิ่ม company/site/grants หลายสาขาตอน provisioning โดยทีม IT; ยังไม่มี UI ครบทุก master. users API ไม่เปิด password hash.
## ทุกบทบาท
โปรไฟล์แก้ชื่อและเปลี่ยนรหัสด้วยรหัสปัจจุบัน. เปลี่ยนรหัสจะออกทุก session. QR บน asset เปิด URL ที่ต้อง login และตรวจ scope. แสดงเวลาไทย; ต้องมีอินเทอร์เน็ตเพื่อบันทึก. ปุ่มออกจากระบบอยู่ด้านขวาบน.

## Phase 3 — PM Advanced (รุ่นปัจจุบัน)
เปิดเมนู บำรุงรักษา PM ในงานซ่อมบำรุง ใช้บัญชี เมนูหลัก และสิทธิ์เดิม มีสามแท็บ:

### ภาพรวมและรายงาน
ค้นหาชื่อแผน/ทรัพย์สิน กรองวันครบกำหนดและสถานะ ช่วงไม่เกิน 366 วัน แบ่งหน้าละ 30 งาน ดาวน์โหลด Excel ทุกหน้าตามตัวกรอง สูงสุด 10,000 งาน
การ์ดสรุปงานคำนวณจากฐานข้อมูลตามตัวกรอง ไม่จำกัดเฉพาะหน้าที่เปิด จำนวนแผนที่ใช้งานนับทุกแผนในพื้นที่ที่มีสิทธิ์

### จัดการแผน PM
Admin/หัวหน้าที่มีสิทธิ์สร้างเพิ่มแผนรายวัน/เดือน เลือกเครื่องจักร ช่างพื้นที่เดียวกัน วันเริ่มต้น Checklist และเตือนล่วงหน้า 0–30 วัน
แก้ชื่อ ช่าง Checklist และรอบได้ตามสิทธิ์แก้ไข เก็บเวอร์ชันและผู้แก้ไข งานที่สร้างแล้วเก็บข้อมูลเดิม หากเปลี่ยนรอบต้องตั้งวันเริ่มต้นตั้งแต่วันนี้ ห้ามเปลี่ยนทรัพย์สินของแผนเดิม
กดประวัติเพื่อดูเวอร์ชันย้อนหลัง แผนจาก Phase 2 เริ่มเก็บ snapshot เมื่อแก้ผ่าน Phase 3
พักแผนหยุดสร้างงานใหม่ ไม่ยกเลิกงานเดิมหรือแจ้งเตือนงานค้าง เปิดกลับทยอยสร้างย้อนหลังต่อ

### ปฏิทินรายเดือน
เลือกเดือนและกรองชื่อ/สถานะ งานจริงกดเปิดได้ เส้นประคือแผนล่วงหน้าที่ยังไม่สร้างงานและยังบันทึกผลไม่ได้ ช่วงวันที่รายงานไม่เปลี่ยนเดือนปฏิทิน

### รูปและผลตรวจ
ช่างเปิดงานของตน แนบ JPG/PNG ก่อนหรือหลังการบำรุง รูปละไม่เกิน 8 MB รวม 20 รูปต่องาน แนบให้ครบก่อนปิดงาน ต้องตั้งค่า R2 ก่อนจึงใช้รูปได้
กรอกผ่าน/ไม่ผ่านทุกข้อและหมายเหตุ แล้วยืนยันผลและปิดงานได้ครั้งเดียว ไม่มีขั้นตอนตรวจรับ PM
งานที่มีข้อไม่ผ่าน: ช่างผู้รับผิดชอบหรือผู้จัดการที่มีสิทธิ์สร้างใบแจ้งซ่อม กดสร้างใบแจ้งซ่อมจากข้อไม่ผ่าน กรอกรายละเอียด ผู้ติดต่อ แผนก และความเร่งด่วน แล้วยืนยัน
ระบบเพิ่มรายการไม่ผ่านและสร้างใบแจ้งซ่อมรออนุมัติ แจ้งผู้อนุมัติ ป้องกันซ้ำหนึ่งใบต่อหนึ่งงาน PM ไม่ได้สร้างอัตโนมัติโดยไม่มีการยืนยัน

### แจ้งเตือนและสิทธิ์
Worker ทุก 5 นาที สร้างงานตั้งแต่เข้าสู่ช่วงเตือนล่วงหน้า (แผนเดิมค่าเริ่มต้น 3 วัน) และส่งแจ้งเตือนล่วงหน้า/ถึงกำหนด/เกินกำหนด อย่างละหนึ่งครั้งต่องาน
เครื่อง worker ที่ตั้งไว้ต้องเปิดและลงชื่อเข้า Windows อยู่ ปิด browser ได้
ช่างเห็นเฉพาะงานของตน ผู้บริหารอ่านได้ ผู้แจ้งซ่อมไม่มีสิทธิ์ PM ทุกบทบาทอยู่ภายใต้บริษัท/พื้นที่และ Permission Matrix
Audit รองรับสร้าง/แก้/เปิด/พักแผน แนบรูป ปิดงาน และสร้างใบแจ้งซ่อมจากผลตรวจ
PM ยังแยกจาก workOrders และ Dashboard งานซ่อมเดิม ยกเว้นใบแจ้งซ่อมที่ยืนยันสร้างจากข้อไม่ผ่าน ยังไม่มีตรวจรับ PM รอบมิเตอร์ สต็อก Email/Teams/LINE หรือ offline

## แก้ไขบริษัท/สาขาของเครื่องจักร
เปิดทะเบียนเครื่องจักร → รายละเอียด → แก้ไขเครื่องจักร → บริษัท → สาขา → สถานที่ → บันทึก
ต้องมีสิทธิ์แก้ไขและเข้าถึงทั้งพื้นที่เดิมและพื้นที่ใหม่ เมื่อเปลี่ยนบริษัท/สาขา ระบบล้างตัวเลือกที่เกี่ยวข้องเพื่อให้เลือกใหม่
เครื่องจักรที่มีข้อมูลอ้างอิง เช่น ประวัติซ่อมหรือ PM จะย้ายบริษัท/สาขาไม่ได้ แต่แก้ข้อมูลทั่วไปได้
