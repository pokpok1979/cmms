# UAT — Phase 3
ใช้ฐานข้อมูลทดสอบและ private R2 bucket ก่อนใช้งานจริง

| ลำดับ | ทดสอบ | ผลที่ต้องได้ |
|---|---|---|
| 1 | Login บัญชีเดิม เปิด /pm/advanced ทั้ง desktop และมือถือ | เปิดภาพรวม/ปฏิทิน/แผนได้ ไม่มีข้อความหรือปุ่มล้นจอ |
| 2 | Admin สร้างแผนรอบเดือน Checklist 2 ข้อ leadDays 3 | บันทึกแผนเวอร์ชัน 0 และช่างต้องมีสิทธิ์พื้นที่เดียวกัน |
| 3 | รัน worker สองครั้ง และทดลองสอง worker พร้อมกัน | งานแต่ละวันไม่ซ้ำ ไม่แจ้งเตือนประเภทเดียวกันซ้ำ |
| 4 | แผน leadDays 0 ที่ยังไม่ถึงกำหนด พร้อมแผนอื่น leadDays 30 | สร้างงานเฉพาะแผนที่เข้าเงื่อนไขเตือน ไม่มีแผนที่เข้าเงื่อนไขถูกข้ามเพราะ limit |
| 5 | ดูปฏิทินเดือนถัดไป | แผนล่วงหน้ามีเส้นประและยังบันทึกผลไม่ได้ งานจริงคลิกเปิดได้ |
| 6 | แก้ Checklist และช่างของแผนที่มีงานแล้ว | เวอร์ชันเพิ่ม งานเดิมยังเป็น Checklist/ช่างเดิม; งานใหม่ใช้ค่าใหม่ |
| 7 | เปิดแผนเดียวกันสองหน้าต่างแล้วแก้พร้อมกัน | ผู้บันทึกด้วยเวอร์ชันเก่าต้องได้รับข้อความข้อมูลเปลี่ยนแล้ว |
| 8 | เปลี่ยนรอบแผนและตั้งวันเริ่มต้นย้อนหลัง | ปฏิเสธ; ตั้งแต่วันนี้เป็นต้นไปจึงบันทึกได้ |
| 9 | รอบใหม่ตรงวันงานเก่าที่มีอยู่ | ไม่สร้างงานซ้ำในวันเดียวกัน งานเดิมไม่ถูกแก้ทับ |
| 10 | ช่างรับผิดชอบแนบรูป JPG/PNG ก่อนและหลัง แล้วเปิดดู | อัปโหลดสำเร็จ รูปเข้าถึงผ่านสิทธิ์บัญชีและ URL ชั่วคราว |
| 11 | ไฟล์เกิน 8 MB / PDF เปลี่ยนนามสกุล JPG / รูปที่ 21 | ปฏิเสธทั้งหมด |
| 12 | ช่างอื่นเรียก API งาน/รูปโดยใช้ ID ที่รู้มา | ไม่เห็น/บันทึก/อัปโหลด/เปิด signed URL ไม่ได้ |
| 13 | ผู้ใช้ต่างบริษัท/ไซต์เรียก API งาน แผน history report export | ไม่เห็นข้อมูลนอกคู่บริษัท/ไซต์ที่ได้รับสิทธิ์ |
| 14 | ปิดงานขณะรูปกำลังอัปโหลด | รูปไม่ถูกแนบหลังปิดงาน ไม่มี metadata ชี้ไฟล์ที่อัปโหลดล้มเหลว |
| 15 | ยืนยัน Checklist ไม่ครบ / ยืนยันซ้ำ | ปฏิเสธ งานเก็บผลได้ครั้งเดียว |
| 16 | งานเสร็จและมีข้อไม่ผ่าน กดสร้างใบแจ้งซ่อมสองครั้ง/พร้อมกัน | มี RR เดียว แสดงเลข RR เดิม ไม่สร้างใบงาน WO จนกว่าจะอนุมัติ |
| 17 | ทรัพย์สินไม่มี location หรือ location ถูกลบ | สร้าง RR ไม่ได้ แจ้งให้กำหนดสถานที่ก่อน |
| 18 | นำ RR ที่ได้ไปอนุมัติ มอบหมาย ซ่อม ตรวจรับ ผ่านระบบเดิม | กระบวนการ Phase 1 ยังทำงานครบ |
| 19 | รัน worker ในช่วงก่อน/ถึง/หลังวันกำหนด | แจ้งเตือนช่างล่วงหน้า วันกำหนด และเกินกำหนด อย่างละหนึ่งครั้ง |
| 20 | กรองรายงานช่วงวันที่/สถานะ/ชื่อ และเปลี่ยนหน้า | รายการ จำนวน และ export ใช้เงื่อนไขเดียวกัน |
| 21 | เปิด .xlsx ด้วย Excel | ภาษาไทยถูกต้อง มี filter และ freeze แถวแรก; ข้อมูลขึ้นต้น = ไม่กลายเป็นสูตร |
| 22 | หยุด worker แล้วปิด browser เปิดกลับทดสอบ Task Scheduler | การสร้างงานไม่ต้องอาศัย browser แต่ต้องมีเครื่อง worker เปิดอยู่ |
| 23 | Login / Users / Audit / งานซ่อมเดิมหลังติดตั้ง | ไม่มีผลกระทบจากชุดใหม่ |

บันทึกผู้ทดสอบ วันที่ ผล และปัญหาที่พบ ก่อนอนุมัติ Production
