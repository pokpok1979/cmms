# อัปเกรด Phase 2 PM — 22 ตุลาคม 2569

ติดตั้ง PM บน Phase1 ปัจจุบันแล้ว เปิดจากเมนู งานซ่อมบำรุง > บำรุงรักษา PM หรือ /pm หลังเข้าสู่ระบบ

## การใช้งาน
- Admin/Supervisor: สร้างแผน เลือกเครื่องจักร ช่าง วันเริ่ม รอบรายวัน/เดือน และ Checklist
- ใช้ปุ่มสร้างงานถึงกำหนด หรือรอ worker สร้างงานตามรอบ
- ช่างผู้รับผิดชอบ: เปิดงาน กรอกผ่าน/ไม่ผ่านทุกข้อและหมายเหตุ แล้วยืนยันผล
- Executive ดูข้อมูลได้; Requester ไม่มีสิทธิ์ PM
- ปรับสิทธิ์ดู/สร้าง/แก้ไขได้ในบทบาท & สิทธิ์ โดยยังอยู่ภายใต้ข้อจำกัดบทบาทและบริษัท/พื้นที่
- แจ้งเตือนเชื่อมไปงาน PM; Audit รองรับสร้างแผน เปิด/พักแผน และปิดงาน

## Scheduler
ติดตั้ง Windows Task ชื่อ AGE-CMMS-PM ทุก 5 นาที สำหรับผู้ใช้ Windows ปัจจุบัน แบบ Interactive / Limited
ต้องเปิดเครื่องและลงชื่อเข้าใช้ Windows อยู่ (ล็อกหน้าจอได้) ปิด browser ได้
สคริปต์ scripts/schedule-pm.ps1 รัน worker แบบซ่อนหน้าต่างและบันทึกผลครั้งล่าสุดที่ .pm-worker.log
ทดสอบ task แล้ว: exit=0, created=0, processedPlans=0
หากย้ายโฟลเดอร์หรือเปลี่ยนพาธ Node ให้รัน powershell.exe -NoProfile -File scripts/schedule-pm.ps1 -Install ใหม่
หากต้องการทำงานตอน Sign out ให้ผู้ดูแลตั้ง Run whether user is logged on or not ด้วยบัญชีบริการที่เหมาะสม

คำสั่ง:
- npm run setup:pm — สร้างดัชนี PM (รันสำเร็จแล้ว)
- npm run pm:worker — ประมวลผลหนึ่งครั้ง
- Disable-ScheduledTask -TaskName AGE-CMMS-PM — พัก worker อัตโนมัติ

## การตรวจสอบ
- npm test: 81 ผ่าน / 0 ไม่ผ่าน รวม calendar และ integration ของสิทธิ์/แจ้งเตือน/Audit PM
- npm run typecheck: ผ่าน
- production build ผ่าน โดยใช้ CMMS_BUILD_DIR=.next-pm-verify เพื่อแยกจาก dev cache
- ตรวจ HTTP production ชั่วคราว: / และ /pm ตอบ 200; /api/pm ขณะไม่ได้เข้าสู่ระบบตอบ 401
- สร้างดัชนี MongoDB และรัน worker จริงสำเร็จ ไม่มีแผนถึงกำหนด จึงไม่ได้สร้างงาน
- ยังไม่ได้ทดสอบ workflow ครบด้วยบัญชีจริงหรือ concurrency หลาย worker บน Atlas

## ขอบเขต
PM แยกจาก workOrders และ Dashboard งานซ่อมเดิม มี Dashboard PM ของตนเอง
ยังไม่มีแก้รายละเอียดแผน/เปลี่ยนช่าง แนบรูป ตรวจรับ PM สต็อก มิเตอร์ หรือสร้างใบแจ้งซ่อมจากข้อไม่ผ่านอัตโนมัติ
