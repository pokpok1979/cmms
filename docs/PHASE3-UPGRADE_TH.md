## เข้าใช้งาน
เมนู งานซ่อมบำรุง > บำรุงรักษา PM
ลิงก์ /pm และ /pm/advanced จะนำเข้าสู่หน้า PM ในโครงหน้าจอหลัก รวมลิงก์จากการแจ้งเตือน
คงการ์ดสรุป ไอคอน สี Animation และ Counter ที่ปรับไว้ พร้อมตารางและการแบ่งหน้าร่วมกับระบบเดิม

## เพิ่มแล้ว
- แก้ชื่อ/รอบ/Checklist/ช่าง/วันเตือนพร้อมเวอร์ชัน งานเดิมไม่เปลี่ยนตาม
- ปฏิทินรายเดือนพร้อมแผนล่วงหน้าแบบเส้นประ
- ภาพก่อน/หลัง JPG/PNG ไม่เกิน 8 MB รวม 20 รูป ต้องแนบก่อนปิดงาน
- ยืนยันสร้างใบแจ้งซ่อมจากข้อไม่ผ่าน ป้องกันซ้ำและแจ้งผู้อนุมัติ
- เตือนล่วงหน้า 0–30 วัน (แผนเดิมเริ่ม 3 วัน) ถึงกำหนด และเกินกำหนด อย่างละหนึ่งครั้ง
- รายงาน/ตัวเลขจากฐานข้อมูลตามตัวกรอง ส่งออก .xlsx สูงสุด 10,000 งาน
- เชื่อม PM permissions, notifications, Audit และคู่มือเดิม
- API Phase2 ที่ยังมีผู้เรียกจะส่งการบันทึกผ่าน service Phase3 เดียวกัน

## สิ่งที่ยังต้องตั้งค่า
ไม่พบการตั้งค่า R2 ครบใน .env.local ขณะอัปเกรด จึงซ่อนแบบฟอร์มอัปโหลดและแสดงข้อความให้ติดต่อผู้ดูแล
ต้องตั้ง R2_ENDPOINT, R2_BUCKET, R2_ACCESS_KEY_ID และ R2_SECRET_ACCESS_KEY ของ private bucket แล้วเริ่ม server ใหม่
ไม่มีการใส่หรือแสดงรหัสลับในเอกสารนี้ ยังไม่ได้ทดสอบ upload/download กับ R2 จริง

## ขอบเขต
ยังไม่มีตรวจรับ PM รอบมิเตอร์ สต็อก Email/Teams/LINE หรือ offline
การสร้างใบแจ้งซ่อมจากข้อไม่ผ่านต้องให้ผู้ใช้ยืนยัน ไม่ได้สร้างอัตโนมัติเอง
PM ยังแยกจาก workOrders และ Dashboard งานซ่อมเดิม ใบแจ้งซ่อมที่ยืนยันสร้างจะเข้ากระบวนการซ่อมเดิม

## ตรวจสอบ
- npm run setup:pm3: สร้าง indexes สำเร็จ ไม่ reset ผู้ใช้หรือรหัสผ่าน
- npm test: 98 ผ่าน / 0 ไม่ผ่าน
- npm run typecheck และ production build: ผ่าน
- node --import tsx scripts/verify-pm3.ts: ทดสอบ MongoDB จริงด้วย collection แยกชื่อเฉพาะ และลบทิ้งหลังทดสอบ
- ทดสอบเวอร์ชันแผน งานเดิมไม่เปลี่ยน สิทธิ์และขอบเขต สอง worker พร้อมกัน ไม่สร้างงาน/แจ้งเตือนซ้ำ
- ทดสอบสร้างใบแจ้งซ่อมพร้อมกัน ได้ RR เดียว แจ้งผู้อนุมัติ และตรวจตัวเลขรายงาน
- ทดสอบเตือนล่วงหน้า เกินกำหนด และพักแผน
- ยังไม่ได้ทดสอบ UI ครบด้วยผู้ใช้จริงหรือ R2 จริง
